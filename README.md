# 罗塞塔石碑希腊文拼片定位器

输入拼片上横向连续的至少四个希腊字母，工具会在罗塞塔石碑的 54 行希腊文转录中搜索；输入越长，匹配位置越精确。工具会给出：

- 所在行号与行内字母位置
- 匹配处的前后文
- 在石碑示意图上的大致位置
- 在用户上传参考图上的可校准位置

## 使用

电脑上可直接双击 `index.html` 使用。若要安装到平板主屏幕并离线使用，请按照下方的 PWA 安装步骤操作。

1. 输入至少四个连续字母。支持大小写、带重音字母、古体弯月形 sigma（Ϲ），并自动忽略空格和标点。
2. 若出现多个结果，逐一查看上下文，并结合拼片的断边或更多相邻字母判断。
3. 可上传自己拼图盒上的完整参考图，然后展开“校准上传图片中的希腊文区域”微调四个百分比。
4. 如果厂商使用的文字版本与内置转录不同，可导入 `.txt` 文件；文件中每一行应对应图上的一行。

也可以用查询参数直接打开某个结果，例如 `index.html?q=ΕΛΛΗ`。

所有搜索和图片处理都只在浏览器内进行，图片不会上传。

## 安装到平板

本项目已经配置为 PWA，无需应用商店，也不需要后端服务器。把整个目录发布到任意支持 HTTPS 的静态网站服务即可，例如 GitHub Pages、Cloudflare Pages 或 Netlify。

1. 用平板浏览器打开发布后的 HTTPS 地址，并等待页面完整加载一次。
2. iPad 使用 Safari：点击“分享” → “添加到主屏幕”。
3. Android 使用 Chrome：点击页面右上方“安装到平板”，或在浏览器菜单中选择“安装应用”。
4. 从主屏幕图标启动。已经缓存的文字搜索、示意图和界面均可离线使用。

注意：直接从“文件”应用打开 `index.html` 仍可搜索，但浏览器不会启用安装与离线缓存；PWA 安装必须通过 HTTPS 地址访问。

## 数据与定位说明

内置原文为 54 行希腊文转录，来源于希腊语维基文库：

<https://el.wikisource.org/wiki/Στήλη_της_Ροζέττας>

方括号代表残缺或学者复原的字符。图上横坐标按该行字母序号估算，纵坐标按行号估算，因此适合快速缩小搜索区域；不同照片的透视、裁切以及不同拼图厂商的排版会造成少量偏差，可通过图片校准或自定义转录修正。
